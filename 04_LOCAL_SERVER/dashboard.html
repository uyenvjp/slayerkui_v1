04

Kiểm tra đăng nhập local

Kiểm tra backend JSON test tại 127.0.0.1:8000. Không phải đăng nhập APK Unity gốc.

Token không được trả về giao diện hay ghi vào log.

Ranh giới tương thích

Client gốc dùng Firebase Guest/Integration JWT, Protobuf và lớp request/response riêng. Backend JSON đang chạy chưa thay thế các hệ thống đó.

  • ADB chỉ cài APK lên điện thoại.
  • Cài đặt thành công không đồng nghĩa đăng nhập game thành công.
  • Không sửa chữ ký APK hoặc bỏ qua xác thực game.
Mã nguồn và tài nguyên gốc trên GitHub ↗

Hướng dẫn nhanh

1. Cài Android Platform Tools (ADB) và đặt adb.exe trong PATH hoặc tools/platform-tools/.

2. Chạy START_WINDOWS.bat rồi mở http://127.0.0.1:8765.

3. Kết nối máy, chọn XAPK đúng bản và nhấn Cài đặt.
